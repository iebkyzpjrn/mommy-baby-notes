# 焦虑症的六大躯体症状有哪些，过来人分享呼吸道问题最为常见。

> 更新时间：2026-09-17 (UTC+8)

焦虑症是一种心理疾病，患者患病后通常会感觉焦虑，而且紧张难安，但是患者换焦虑症是也可以治疗的，不过也有一些人并不知道什么是焦虑症，其实患者出现泌尿系统症状、植物神经症状时就需要多加注意，此时很可能是患上了焦虑症焦虑症又称焦虑性神经症，是最常见的一种神经症，表现为焦虑的情绪体验。但很多患者并不是情绪上的表现，而主要是来自身体的某个部位，如呼吸不畅、四肢疼痛、心慌胸闷、腹泻等，患者应该注意辨别

## 分享焦虑症的六大躯体症状

- 1. 呼吸道症状：焦虑症患者会觉得呼吸特别困难，这主要是由于吸气不足、胸闷、呼吸不畅、叹气呼吸甚至窒息的主观感觉；
- 2. 心血管症状：有些患者会感到头晕，心跳加快，血压升高，部分患者有心前区疼痛、针状或钝痛等，这些症状可能持续数小时，粗糙部分伴有压痛；而且有的患者会心慌心悸；
- 3. 消化系统症状：焦虑症患者除了上述的食欲不振外，还会出现口干、口中无味、恶心呕吐、腹痛、腹泻、腹胀、消化不良、便秘等症状，同时会感到上腹部不适，但又说不出具体的感受；
- 4. 泌尿系统症状：部分男性患者会出现尿频、尿急和勃起功能障碍，性欲冷淡，女性患者会出现月经紊乱和痛经；
- 5. 植物神经症状：躯体焦虑常伴有手足多汗，急性发作常引起出汗等自主神经功能障碍症状，躯体焦虑与自主神经系统功能密切相关，焦虑本身就是对情绪的一种反应，受自主神经系统的影响，研究发现，当植物神经系统功能紊乱时，如多动，受其支配的器官会出现躯体化反应。
- 6. 肌肉运动系统症状：比较常见的是头颈部、面部、四肢等部位肌肉紧张引起的收缩性或挤压性头痛，以前额前部或后枕部较为明显，此外，颈、肩、腰、背感觉僵硬疼痛，严重时会出现震颤、抽搐。

在沉重的生活压力下，现在越来越多的人患上了焦虑症，这不仅会影响人的心理健康，而且当疾病发展到一定阶段而不采取更好的措施加以控制时，还会引起麻烦的躯体化症状。
